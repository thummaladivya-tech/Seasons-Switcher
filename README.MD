# Seasons Switcher 🌸

A simple and interactive Seasons Switcher web application developed using HTML, CSS, and JavaScript.

## Features
- Displays seasonal images.
- Switches between Spring, Summer, Autumn, and Winter.
- Interactive buttons.
- Simple and user-friendly interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
